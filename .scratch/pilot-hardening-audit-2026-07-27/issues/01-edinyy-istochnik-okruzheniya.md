# 01 — Единый источник истины окружения (N2)

**What to build:** Деплойщик поднимает Ai-dos и через systemd, и через `run_api.sh` — и
получает ОДНУ и ту же топологию (русский F5 на GPU-ноде АФМ, казахский ElevenLabs, STT
через сервер АФМ). Окружение сервисов задаётся в одном месте, подключаемом обоими путями
запуска, поэтому «деплой по инструкции» больше не расходится с пилотным дефолтом.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Провайдеры/адреса TTS, STT, RAG задаются в едином источнике окружения, который
      подключают и systemd-юниты, и `run_api.sh` (дублирования одних и тех же переменных
      в разных местах нет).
- [ ] Дефолтная пилотная топология (ru = F5-GPU, kk = ElevenLabs, STT = сервер АФМ) —
      единственный дефолт во всех точках запуска.
- [ ] `/health` отражает активную топологию (имена провайдеров ru/kk).
- [ ] Deploy-README описывает единый способ; если оставлены два набора юнитов
      (local-TTS vs GPU+ElevenLabs) — явно указано, какой когда применять.
- [ ] Существующий набор тестов (pytest + node) зелёный.
