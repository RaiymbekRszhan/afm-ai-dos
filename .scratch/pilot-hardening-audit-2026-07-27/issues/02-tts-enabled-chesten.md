# 02 — `tts_enabled` честен при пустом URL (N3)

**What to build:** Деплойщик, забывший задать адрес TTS-провайдера, узнаёт об этом из
`/health` (и на старте), а не от гражданина, получившего 502 у экрана. Провайдер `f5`/
`spark` считается сконфигурированным только когда задан его URL — так же, как это уже
проверяется для `eleven`/`openai`.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] При выбранном провайдере `f5`/`spark` и пустом соответствующем `*_url`
      `tts_enabled` = false; `/health.tts.enabled` это отражает.
- [ ] При заданном URL `tts_enabled` = true.
- [ ] Если нужен режим «локальный без URL» — он выражен явно, а не как побочный эффект.
- [ ] Юнит-тесты конфига покрывают оба случая (по образцу существующих тестов настроек).
- [ ] Набор тестов (pytest + node) зелёный.
