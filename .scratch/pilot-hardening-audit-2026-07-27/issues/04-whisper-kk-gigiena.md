# 04 — Гигиена `whisper_kk_server` (N8)

**What to build:** Казахский Whisper-сервер переживёт апгрейд FastAPI, слушает
настраиваемый адрес и не отдаёт наружу сырые детали ошибок. Поведение распознавания не
меняется.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Прогрев/загрузка модели переведены со `@app.on_event("startup")` на `lifespan`.
- [ ] Адрес прослушивания вынесен в переменную окружения (дефолт можно оставить
      `0.0.0.0` для GPU-ноды, но он настраиваем — как у f5/spark).
- [ ] Ошибка синтеза наружу обезличена (общее сообщение + 5xx); подробности — только в лог.
- [ ] Сервис стартует и отвечает `/transcribe` (контракт `{"status":"success","data":...}`)
      как прежде.
