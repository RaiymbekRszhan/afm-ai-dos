# 05 — Единый список триггеров печати бланков (N9)

**What to build:** Триггеры «предложить печать бланка» (заявление ФЛ/ЮЛ, запись на
личный приём) едины для бэкенда (авторитетный `print` в ответе) и фронта (демо-фолбэк),
и не расходятся со временем. Одинаковый ответ даёт одинаковый набор бланков на обеих
сторонах.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Список/правила триггеров печати сведены к единому источнику для бэкенда и фронта
      (общий ресурс либо контрактный тест, сверяющий обе стороны).
- [ ] Один и тот же текст ответа даёт один и тот же набор бланков (`fl`/`ul`/`priem`) на
      бэкенде и на фронте.
- [ ] Расхождение `подач` vs `податч` устранено.
- [ ] Существующие тесты детекции печати (pytest + node) зелёные.
