# 09 — Сужение сетевой поверхности + `/docs` за флагом (N6)

**What to build:** Оркестратор больше не доступен всей сети киоска без нужды: по
умолчанию он слушает `127.0.0.1`, а внешний вход — только через киоск-страницу
(`video_ui`) на той же машине. Swagger `/docs` выключен в проде. UX гражданина не
меняется — он по-прежнему ходит на `video_ui`.

**Blocked by:** 01 — Единый источник истины окружения (правит те же deploy/`run_api`
env-файлы; сериализуем, чтобы не разрушить единый источник).

      (для случая «за TLS-reverse-proxy»).
