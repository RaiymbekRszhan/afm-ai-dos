### ⛔ Не исправлено сейчас — требует инфраструктуры/решений/доступа

1. **TLS-терминация (critical, #1)** — вне кода: нужен реверс-прокси (nginx/caddy) + внутренний CA АФМ. Без него `getUserMedia` не работает на киоске, а ПДн ходят по LAN открытым текстом. **Рекомендация:** caddy/nginx на 443 с самоподписанным CA АФМ → proxy на `127.0.0.1:8000`; тогда и API-сервис можно сузить до localhost. Пока оставил bind API `0.0.0.0` (браузеры граждан ходят напрямую) — это связано с решением по TLS.
2. **Доставка скрипта ноды по HTTP (high, #3)** — добавлен опциональный токен на `/last_answer*`, но сам механизм «нода качает `aidos_editor.py` по HTTP и исполняет» остаётся. Полное решение — ручная доставка файла либо подпись/чексумма поверх TLS (см. п.1). Меняет процесс деплоя ноды — на согласование.
3. **Удаление старых редакций из базы RAG (high, #5)** — кэш отключён (закрывает устаревшие ответы), но переингест по-прежнему не удаляет старые чанки (`uid = md5(текста)`). Правильно — пересобирать `rag_storage` при обновлении `data/` или `adelete_by_doc_id` со стабильным `doc_id` по номеру статьи. Риск потери данных при неверной реализации — оставляю на согласование + процедуру эксплуатации.
4. **Prompt injection — полное закрытие (high, #4)** — защитный блок в промпт добавлен (снижает риск), но на уровне LLM гарантии нет. Нужна пост-валидация ответа (проверка языка/тематики) и/или отдельный классификатор — отдельная фича с оценкой качества на датасете.
5. **Реальная пиновка зависимостей (medium)** — `f5_server/requirements.txt` и `rag/requirements.txt` не запинены. Нужен `uv pip compile` в среде с доступом к pypi (в сети АФМ его нет) + пин коммита Spark-TTS и `--revision` моделей HF со сверкой sha256. Требует прогона там, где есть интернет.
6. **Комплаенс ПДн — политика логов (medium/high, #12)** — вопросы граждан больше не копятся в кэше RAG (кэш выключен), но guard-лог всё ещё пишет `question[:200]`, а политика хранения/ротации/шифрования логов — организационное решение АФМ, не код.
7. **Дедупликация JS-рекордера в `/static/recorder.js` (medium)** — не выносил: меняет структуру статики и требует браузерного теста на киоске. Точечные баги дублированного кода (блокировка кнопки, revoke) при этом уже исправлены в `index.html`.
8. **Внутренние IP в `.env.example` и дефолтах конфигов (medium)** — не менял: это рабочие адреса АФМ, на которые опирается дев-окружение; замена на плейсхолдеры — решение команды (для приватного репо приемлемо).
9. **`AudioWorklet` вместо `createScriptProcessor` (low)** и **`Type=notify` readiness в systemd (low)** — работающие, но deprecated/неидеальные места; миграция — отдельные задачи с тестированием.

## Приоритетные рекомендации (по убыванию)

1. **TLS-терминация** (реверс-прокси с внутренним CA АФМ) — одним махом закрывает блокер микрофона (№1), перехват ПДн в заголовках и MITM при доставке скрипта ноды (№3).
