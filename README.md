# Цифровой офицер «Ai-dos» — голосовой консультант АФМ

FastAPI-оркестратор: распознаёт речь, получает ответ **строго по базе** кодексов и
законов РК (отдельный RAG-сервис) и озвучивает его. Двуязычный (русский + казахский),
с роутингом по языку.

```
Аудио ─► STT ─► (коррекция LLM) ─► RAG-сервис /ask (поиск по базе + LLM) ─► текст ─► TTS ─► WAV
                                   └──────── ответ строго по базе, без выдумывания ────────┘
```

Бэкенд отдаёт **готовый озвученный ответ (WAV)**. «Лицо» — киоск-страница
**video_ui** (`:8100`): записанные ролики аватара, таблицы и графики из базы, QR-коды
порталов, караоке-подсветка.

Источник ответа — **RAG-сервис на :8077** (LightRAG — векторный поиск по смыслу поверх
эмбеддингов/LLM АФМ; граф знаний не используется), отвечающий строго по официальной базе
кодексов и законов РК на русском и казахском.

## Архитектура

Основные сервисы — оркестратор, RAG и киоск-страница. TTS по умолчанию — облачный
**ElevenLabs** (нужен интернет; лучший казахский голос). Офлайн-фолбэк TTS (F5/Spark)
и вынос STT на GPU АФМ — отдельные сервисы, каждый в **своём venv** (зависимости
конфликтуют), общаются по HTTP.

| Сервис | Порт | venv | Папка | Назначение |
|--------|------|------|-------|-----------|
| **Оркестратор** | 8000 | `.venv` | `app/` | FastAPI: STT → RAG → TTS, тест-UI, Swagger |
| **RAG-сервис** | 8077 | `rag/.venv` | `rag/` | LightRAG-поиск по базе РК, ответ строго по базе |
| **video_ui** | 8100 | `.venv` | `video_ui/` | киоск-страница «видео-аватар» ([README](video_ui/README.md)) |
| **ElevenLabs** | — | — | облако | основной TTS (рус+каз, `eleven_v3`); ⚠️ нужен интернет |
| _F5_ (рус TTS) | 8810 | `.venv-f5` | `f5_server/` | офлайн-фолбэк русского TTS (опц.) |
| _Spark_ (каз TTS) | 8809 | `.venv-spark` | `spark_server/` | офлайн-фолбэк казахского TTS (опц.) |
| _Whisper-kk_ (каз STT) | 8813 | `.venv-whisper-kk` | `whisper_kk_server/` | вынос казахского STT на GPU АФМ (опц.) |

Страница киоска проксирует вопросы на `:8000` (same-origin, CORS не нужен) и
показывает поверх пайплайна: ролики idle/talk, таблицы+бар-чарты из базы, QR-коды
порталов, увеличение по тапу, караоке-подсветку и автопрокрутку.

| Этап | Русский | Казахский |
|------|---------|-----------|
| **STT** (речь→текст) | сервер АФМ `:8804` | сервер АФМ `:8804` (он тянет и казахский; `Whisper-kk` — опц. фолбэк) |
| **RAG+LLM** | RAG-сервис `:8077` (embedding `:8806` + LLM `:8901` АФМ, векторный поиск) | то же |
| **TTS** (текст→речь) | **ElevenLabs `eleven_v3`** (офлайн-фолбэк — F5-TTS) | **ElevenLabs `eleven_v3`** (офлайн-фолбэк — Spark-TTS) |

## Структура
- `app/` — оркестратор: `main.py` (эндпоинты), `config.py`, `service.py` (коррекция STT),
  `clients/` (llm · stt · tts · **rag**), `static/` (тест-страница)
- `rag/` — **RAG-сервис** (LightRAG, свой venv и README внутри): `ragsvc/` (код),
  `data/` (база знаний `.md`), `rag_storage/` (индекс после `ingest`), `.env`
- `f5_server/` (рус), `spark_server/` (каз) — офлайн-фолбэк TTS; `whisper_kk_server/` —
  вынос казахского STT на GPU АФМ (у каждого setup/run/README внутри)
- `refs/` — образцы голоса для офлайн-фолбэка (`ref_ru_f5.wav`+`ref_ru.txt` — референс F5; `ref_kk.*` — Spark)
- `video_ui/` — киоск-страница «видео-аватар» (:8100): ролики, таблицы, QR, README внутри
- `tests/` — pytest оркестратора (офлайн, внешние сервисы замоканы): `python -m pytest`
- `run_api.sh` — поднимает весь стек одной командой (`USE_ELEVEN=1` — TTS на ElevenLabs)

## Локальный запуск
Разовая установка (на Wi-Fi — нужен интернет для пакетов/моделей).
> Рекомендуется **uv** (быстрее, воспроизводимее): ниже замени `python3 -m venv` → `uv venv`
> и `pip install` → `uv pip install`. Зависимости объявлены в `pyproject.toml` каждого сервиса.
```bash
# 1) основной API
uv venv .venv && source .venv/bin/activate      # без uv: python3 -m venv .venv && source .venv/bin/activate
uv pip install -r requirements.txt              # без uv: pip install -r requirements.txt
deactivate

# 2) RAG-сервис — ОТДЕЛЬНЫЙ venv (lightrag/torch конфликтуют с голосовым слоем)
cd rag
uv venv .venv && source .venv/bin/activate      # без uv: python3 -m venv .venv && source .venv/bin/activate
uv pip install -r requirements.txt              # без uv: pip install -r requirements.txt
cp .env.example .env                    # заполни LLM_BASE_URL / LLM_MODEL
python -m scripts.check                 # размерность эмбеддинга → EMBEDDING_DIM
                                        #   (qwen3-embedding-8b = 4096; нужен сервер АФМ)
python -m ragsvc.ingest                 # загрузить базу в rag_storage/
cd .. && deactivate

# 3) TTS-сервисы
bash f5_server/setup.sh                 # русский TTS (F5)
bash spark_server/setup.sh              # казахский TTS (Spark)
```
Запуск **одной командой** (Ctrl-C гасит всё):
```bash
bash run_api.sh                 # офлайн-фолбэк TTS: f5 (8810) + spark (8809) + rag + API + video_ui
USE_ELEVEN=1 bash run_api.sh    # основной путь: TTS на ElevenLabs (нужен интернет)
```
Открой **http://localhost:8000/** — тест-страница с микрофоном. Swagger: `/docs`.

> Полный цикл требует доступа к серверам АФМ (кабель): STT `:8804`, LLM/эмбеддинги
> `192.168.165.2`. Казахский STT теперь тоже на сервере АФМ. Офлайн-TTS (F5/Spark)
> работают без интернета; ElevenLabs требует интернет.

## TTS: длинные ответы и нормализация
TTS обрезает текст длиннее ~182 симв. Поэтому в `app/clients/tts.py` длинный ответ
режется по предложениям до `TTS_MAX_CHARS` (≈180), синтезируется по частям и
склеивается в один WAV. Короткий ответ синтезируется как раньше, одним куском.

Перед синтезом текст нормализуется **только для звука** (ответ на экране/в JSON не
меняется), `_normalize_for_tts()`:
- **юр-аббревиатуры раскрываются полностью**: `статья 218 УК РК` → «…статьи 218
  Уголовного кодекса Республики Казахстан» (после номера статьи — родительный падеж,
  иначе именительный); так же УПК/КоАП/ГК/НК, ПОД/ФТ, ФТ, СФМ; казахские склоняемые
  аббревиатуры — с переносом падежа: `ҚК-нің` → «Қылмыстық кодекстің»;
- **латиница** → произносимый вид: известные бренды по словарю (Kaspi → «Каспи»,
  WhatsApp → «вотсап»), остальное — приближённой транслитерацией (Google → «гугл»);
- **телефоны/горячие линии по цифрам**: «по номеру 1458» → «…один четыре пять восемь»
  (kk: «бір төрт бес сегіз»); короткие «приказ № 55» остаются числительными;
- **числа → слова** на обоих языках (`num2words` казахский не умеет — конвертер свой):
  - количественные: `50 000` → «елу мың» / «пятьдесят тысяч»;
  - **порядковые** в юридических ссылках с согласованием: `214-бап` → «екі жүз он
    төрт**інші** бап», `статья 214` → «статья двести четырнадцат**ая**», годы;
  - проценты (`20%` → «жиырма пайыз»), дроби (`1,5%` → «бір бүтін оннан бес пайыз»);
  - длинные коды (ЖСН/БСН, телефоны) — по цифрам, а не гигантским числом;
- куски без букв (одни цифры/знаки) отсекаются — иначе Spark выдаёт 0 токенов и падает.

Spark-сервер на вырожденной генерации (0 семантических токенов) **повторяет синтез**
(`SPARK_RETRIES`, по умолч. 2) и отдаёт понятный `422` вместо `500`, если не вышло.

## Голоса
Основной TTS — **ElevenLabs**: голос выбирается в аккаунте (`ELEVENLABS_VOICE_ID`),
модель `eleven_v3` сама определяет язык (рус/каз одним голосом). Ключ/голос — в `.env`.

Офлайн-фолбэк: **F5** (русский) говорит «в тембр» референс-аудио `refs/ref_ru_f5.wav`
+ транскрипт `refs/ref_ru.txt` (задаётся в `f5_server/run.sh` через `F5_REF_AUDIO`/
`F5_REF_TEXT`; сменить — `python f5_server/transcribe_ref.py`); **Spark** (казахский) —
голос по умолчанию.

## Ключевые ограничения (важно)
- **Сеть АФМ без интернета** — все пакеты/модели качать заранее на Wi-Fi; на сервере `HF_HUB_OFFLINE=1`.
- **Не сливать venv `rag/` с голосовым слоем** — `lightrag`/`torch` конфликтуют.
- **venv не переносятся** Mac↔Linux — пересоздавать на сервере.
- Сильный TTS даёт полную скорость **на GPU**; на CPU работает, но медленно.
