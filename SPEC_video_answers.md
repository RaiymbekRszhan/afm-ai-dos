# Implementation Spec — Видео-ответы цифрового офицера Ai-dos (Unreal)

Статус: **M1–M2 ДОСТИГНУТЫ, автоматизация работает** (2026-07-02, прогон в сети АФМ).
Заменяет прежнюю Unity-редакцию (Unity/uLipSync/Recorder — отменены, стек ушёл в Unreal).

## 0. Что уже реализовано (сводка 2026-07-02)

- **Сквозной живой цикл работает**: вопрос голосом в браузере (`/avatar` или `/`) →
  STT → RAG → TTS на Маке → рендер-нода сама забирает ответ (`GET /last_answer`,
  авторежим `a.watch()`) → аватар отвечает губами. Ручной труд на клип — ноль команд.
- **Автоматизация в UE** (`unreal/aidos_editor.py`, см. README там): импорт WAV →
  MetaHuman Performance (Process ~3 с на RTX 3050) → экспорт Level Sequence без
  диалогов (цель — класс эталонного актора v03) → авто-позиция → авто-Play.
- **Веб-фронтенд гражданина** `GET /avatar`: живое видео аватара (Pixel Streaming
  с ноды) + кнопка микрофона на одной странице.
- **Озвучка**: юр-аббревиатуры раскрываются полностью, телефоны по цифрам,
  латиница транслитерируется (`app/clients/tts.py`).
- Открыто: MP4 через Movie Render Queue (пока пишем OBS'ом), доступ к Pixel
  Streaming с других устройств (сервер сигнала слушает 127.0.0.1), GPU-сервер АФМ
  (уберёт 2–4 мин ожидания TTS), realtime-губы (Live Link Audio, есть в 5.7).

## 1. Цель

Прогнать полный пайплайн **STT → RAG → TTS → аватар** и получать материалы, где
MetaHuman-офицер **Айдос**:
- голосом **проговаривает ответ модели** (липсинк по звуку),
- результат сохраняется как **видеоролик (MP4)** для показа руководству и приёмки пилота.

## 2. Что уже готово (фундамент)

- **Бэкенд** (движок-агностичен, менять не нужно): оркестратор `:8000`
  (`/transcribe`, `/chat`, `/speak`, `/voice`, `/health`), RAG `:8077`, TTS F5 `:8810` /
  Spark `:8809`. `/voice` отдаёт WAV + заголовки `X-Answer` (текст ответа) и `X-Question`.
  Uvicorn уже слушает `0.0.0.0:8000` → доступен по сети другой машине.
- **Аватар**: Unreal Engine **5.7**, MetaHuman `BP_AFM_agent`. Лицо изначально
  заведено через **ARKit Live Link** (перформанс-каптур с айфона). Плагины проекта:
  MetaHuman(+CoreTech/Character/Calibration/LiveLink), AppleARKit(+FaceSupport), LiveLink,
  Takes, MovieRenderPipeline, PixelStreaming, PythonScriptPlugin.
- **Липсинк по WAV работает** (проверено): аватар проговаривает поданный WAV-файл с
  синхронной артикуляцией.

## 3. Инфраструктура

- **Бэкенд** — на Маке (M4, 16 ГБ). TTS локальный (F5/Spark), офлайн, но на CPU
  **медленный: ~1.5–2 мин на озвучку**. RAG требует внутренний LLM АФМ (`192.168.165.2`)
  — работает только из сети АФМ.
- **Рендер-нода** — отдельный Windows-ноут (RTX 3050, ~7 ГБ RAM, 30 fps) с Unreal.
  Тяжёлый MetaHuman не делит память с бэкендом.
- **Связь**: Windows → `http://<IP-Мака>:8000` (в одной локальной сети; порт 8000 открыт;
  фаервол Мака разрешает входящие). Наружу торчит только `:8000`; RAG/TTS за оркестратором.
- **Офлайн АФМ**: интернета нет → все плагины/зависимости вендорить локально заранее.

## 4. Липсинк: выбранный подход

**Вариант 1 — Epic MetaHuman Audio-Driven Animation (ВЫБРАН, бесплатно, офлайн).**
Встроен в MetaHuman (плагин **MetaHuman Animator**), модель отдельно качать не нужно —
подходит для офлайна АФМ. Пер-клиповый офлайн-процесс: WAV → лицевая анимация (губы +
эмоции + моргание + движение головы) → Sequencer → запись/рендер MP4. Не realtime, но
для видео-ответов руководителю этого достаточно и качество максимальное.

**Вариант 2 — Runtime MetaHuman Lip Sync (платный, Fab) — на будущее.** Даёт **realtime**
(живой микрофон → ответ вживую), фонемный, офлайн-локальный, язык-агностичный (ru/kk),
пишет ARKit-кривые. Companion: Runtime Audio Importer (есть бесплатная open-source версия
на GitHub). Брать, если понадобится интерактив в реальном времени.

(NVIDIA Audio2Face — отклонён: тяжёл для RTX 3050/4 ГБ VRAM, ACE-контейнер сложно
вендорить офлайн. OVRLipSync — end-of-life и не пишет ARKit-кривые MetaHuman.)

## 5. Поток генерации одного ролика (Вариант 1)

1. Вход: вопрос (текст или аудио) + `lang` (russian/kazakh).
2. Бэкенд: аудио → `POST /voice` (или текст → `/chat` + `/speak`) → `answer_text` + `answer.wav`.
3. `answer.wav` попадает в UE-проект как **SoundWave** (перенос файла на рендер-ноду).
4. Unreal (MetaHuman Animator):
   - Content Browser → правый клик → **MetaHuman Animator → MetaHuman Performance**;
   - Input Type = **Audio**, Sound Wave = `answer.wav`, Visualization Mesh = меш лица MetaHuman;
   - **Process** → лицевая анимация;
   - **Export Level Sequence** (назначить `BP_AFM_agent`) → добавить Audio-трек с `answer.wav`.
5. **Play** в Sequencer / **Movie Render Queue** → MP4 (видео+звук в одном файле).
6. Рядом сайдкар `<id>.json`: `{question, answer, sources, lang, duration_sec}`.

## 6. Запись видео

- Быстро: **OBS / QuickTime** поверх окна во время Play (звук+картинка в одном файле).
- Чисто: **Movie Render Pipeline** (плагин включён) → рендер Level Sequence в MP4 (H.264+AAC),
  720p/1080p, 30 fps.

Прежний Unity-блокер (Recorder писал видео немым) в Unreal **не возникает**: звук — это
Audio-трек в Sequencer / внешняя запись экрана.

## 7. Автоматизация (следующий этап)

Включён **PythonScriptPlugin** → пакетную генерацию (список вопросов → набор клипов) можно
скриптовать в редакторе: импорт WAV → Performance → Process → Export → Movie Render Queue.
На MVP — ручной цикл по клипу; автоматизация после того, как один ролик проходит от начала
до конца.

## 8. Открытые вопросы / развилки

1. Live STT→RAG проверять в сети АФМ (LLM `192.168.165.2` извне недоступен). TTS→аватар
   проверяется где угодно (TTS локальный).
2. Ускорение TTS (GPU) — чтобы убрать паузу ~2 мин, если понадобится интерактив.
3. Фон/брендинг кадра (герб/флаги АФМ), свет, субтитры текста ответа.
4. Realtime (Вариант 2) — только если руководству нужен живой микрофон, а не ролики.
