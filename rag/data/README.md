# База знаний RAG

Сюда кладутся документы, по которым отвечает аватар — **строго по этой базе**.
Чем полнее и точнее база, тем меньше вопросов улетает в «нет информации → 1458».
Сейчас здесь только seed (выдержки Закона о ПОД/ФТ + FAQ + справка) — это мало
для реального покрытия.

## Формат файла
Каждый `.md`/`.txt` начинается со служебных строк-метаданных:
```
# LAW: Полное название документа
# SHORT: Короткая метка (станет ЦИТАТОЙ в ответе, напр. «УПК РК»)
# TYPE: code | faq | reference
# LANG: ru | kk
```
Дальше — тело. Нарезка зависит от `TYPE` (см. `ragsvc/chunking.py`):

| TYPE | Как режется | Метка-цитата |
|------|-------------|--------------|
| `code` | по статьям: `Статья N` (ru) / `N-бап` (kk) | `SHORT, статья N` |
| `faq` | пары «вопрос/ответ», разделённые строкой `===` | `SHORT: <начало вопроса>` |
| `reference` | по абзацам (пустая строка — разделитель) | `SHORT: <начало абзаца>` |

## Как добавить документ
1. Положи файл в `data/` с правильным заголовком. **Текст бери из официального
   источника** (adilet.zan.kz, сайт АФМ) — не пересказывай и не сокращай нормы,
   иначе цитата будет неверной (это противоречит главной задаче «не выдумывать»).
2. Перезагрузи базу:
   ```bash
   cd rag && source .venv/bin/activate
   python -m ragsvc.ingest                 # вся папка
   python -m ragsvc.ingest data/upk.md     # один файл
   ```
   Дедуп по `uid` (md5 текста): повторная загрузка не плодит копии, изменённый
   текст обновляется.
3. Добавь несколько вопросов по новому документу в `eval/dataset.yaml` и прогони
   `python -m eval.run_eval`.

## Что докинуть в первую очередь (нужны исходные тексты от вас)
- **Полный Закон о ПОД/ФТ** (сейчас только ст. 3–5).
- **Профильные кодексы**: УК, УПК, АПК РК — те статьи, по которым реально спрашивают.
- **FAQ по реальным обращениям** граждан в call-центр 1458 (это самый частый трафик).
- **Казахские версии** ключевых документов (`LANG: kk`, нарезка по `N-бап`).

## Версионирование (на будущее)
Законы меняются. Указывай дату редакции в `# LAW:` и обновляй базу при изменении норм —
ответ по устаревшей редакции = ошибка.
