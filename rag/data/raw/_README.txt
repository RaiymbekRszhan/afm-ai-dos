СЮДА КЛАДИ ИСХОДНЫЕ ФАЙЛЫ (Word .docx, .pdf, .txt) — на русском и казахском.

Эта папка — НЕ база знаний: ingest её игнорирует (.docx — не тот суффикс,
а этот файл начинается с «_»). Это «приёмник» для сырых документов.

Что делать:
1. Положи сюда файлы (можно как есть из интернета: adilet, сайт АФМ).
2. Напиши Claude по каждому файлу: что это (закон / кодекс / FAQ / справка)
   и язык (ru / kk).
3. Claude сконвертирует, разметит заголовком (# LAW/SHORT/TYPE/LANG),
   нарежет по статьям и положит готовый .md в rag/data/.
4. Перестроим индекс: python -m ragsvc.ingest

Называй файлы понятно, напр.: podft_ru.docx, podft_kk.docx, upk_ru.docx
