# Рендер-нода: говорящий MetaHuman-аватар (Unreal 5.7)

`aidos_editor.py` — editor-скрипт для Python-консоли Unreal. Превращает ответ
бэкенда (WAV) в говорящего аватара: импорт → MetaHuman Performance (Epic
Audio-Driven Animation, офлайн, ~3 с на RTX 3050) → Level Sequence → Play.

Требования на ноде: UE 5.7 + плагины MetaHuman (Animator), PythonScriptPlugin,
PixelStreaming2 (для живого видео в браузер); проект с MetaHuman-актором в сцене.

## Установка

1. Скачать актуальную версию с бэкенда: `http://<IP-Мака>:8000/static/aidos_editor.py`
   (файл раздаётся из этой папки — на ноду копий руками не носить).
2. Положить в `<проект UE>/Content/Python/aidos_editor.py`.
3. В консоли UE (внизу, переключить на Python):
   ```python
   import aidos_editor as a           # после обновления файла:
   # import importlib, aidos_editor; importlib.reload(aidos_editor); a = aidos_editor
   ```

## Команды

| Команда | Что делает |
|---|---|
| `a.watch()` / `a.stop_watch()` | **авторежим**: long-poll бэкенда в фоновом потоке (`/last_answer/wait`) — новый голосовой ответ играет сам, мгновенно |
| `a.play_last()` | забрать последний ответ с бэкенда и проиграть (разовая ручная версия watch) |
| `a.ask_text("вопрос", "russian"/"kazakh")` | текстовый вопрос → RAG → TTS → аватар |
| `a.ask_voice(r"C:\путь\вопрос.wav", lang)` | голосовой вопрос из WAV-файла |
| `a.ask_take(lang)` | вопрос, записанный микрофоном в UE (Take Recorder → Microphone Audio) |
| `a.fix_spawn_transform()` | поставить аватара открытой секвенции на место эталона |
| `a.show_idle()` | вернуть скрытый манекен-эталон (если сцена опустела) |
| `a.cleanup()` | удалить артефакты прошлых ответов (WAV/Perf/секвенции); после каждого нового ответа вызывается сама |
| `a.resume("/Game/...")` | продолжить с уже импортированного SoundWave |
| `a.dump_api()` / `a.dump_export_settings()` / `a.dump_template()` | диагностика API (прислать вывод при ошибках) |

## Константы (верх файла / секция v3)

- `BACKEND` — адрес оркестратора (`http://<IP-Мака>:8000`); IP в сети АФМ выдаётся
  DHCP — проверять `ipconfig getifaddr en7` на Маке.
- `REFERENCE_ACTOR = "BP_AFM_agent_v03"` — актор сцены: даёт позицию и Blueprint-класс
  для спавненного аватара. Может быть скрыт — скрипту не мешает.
- `CONTENT_DIR = "/Game/Aidos/Answers"` — куда складываются WAV/перформансы/секвенции.
- `SAVE_DIR` — WAV-файлы на диске ноды (`<проект>/Saved/Aidos`).

## Как это работает (и грабли, на которых уже стояли)

1. WAV ответа → SoundWave → `MetaHumanPerformance` (Input=Audio, блокирующий
   `start_pipeline`) → анимация лица.
2. Экспорт Level Sequence **без диалогов**: `target_meta_human_class` ждёт
   **Blueprint-ассет** (не класс!), берётся у `REFERENCE_ACTOR`;
   `export_transform_track=False` — иначе экспорт запекает кривую позицию капчура;
   камера не экспортируется — кадр держит вьюпорт (навести один раз).
3. Спавненный аватар секвенции ставится на позу эталона (`fix_spawn_transform`
   пересоздаёт transform-трек). Спавненный живёт, пока секвенция открыта, — он и
   есть «дежурный» аватар в кадре; манекен-эталон скрывается насовсем.
4. **Editor-скрипты не работают в Play-режиме** — остановить Play перед командами.
5. Имена привязок в секвенции — с пробелами («BP AFM Agent V 03»), сравнение в
   скрипте нормализовано.

## Живое видео в браузер (Pixel Streaming)

Тулбар → Pixel Streaming 2 → «Запустить сервер передачи сигнала» (Streamer 8888,
Viewer 80) → «Транслировать редактор уровня». Плеер не вшит в движок: один раз, С
ИНТЕРНЕТОМ, запустить `get_ps_servers.bat` из
`...\UE_5.7\Engine\Plugins\Media\PixelStreaming2\Resources\WebServers` (в сети АФМ
интернета нет — сделать заранее). Проверка: `http://127.0.0.1` на ноде.
Страница для гражданина — `http://<IP-Мака>:8000/avatar` (адрес потока вводится там).
Известное ограничение: встроенный сервер сигнала слушает `127.0.0.1` — доступ к
потоку с других устройств пока не настроен.

## Звук

Громкость Windows-ноды — в ноль: звук аватара уходит в браузер вместе с видео
(Pixel Streaming), локальные колонки дают эхо и рассинхрон.

## Микрофон в браузере (страницы `/` и `/avatar`)

Браузер блокирует микрофон на `http://<IP>`: включить
`chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать
`http://<IP-Мака>:8000`, Enabled, Relaunch. При смене IP — обновить запись во флаге.
