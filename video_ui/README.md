# Вариант 2 — «видео-аватар» (демо для сравнения)

Тот же голосовой сценарий, что и рабочий вариант 1, но **без Unreal и render-ПК**:
вместо реалтайм-рендера крутятся заранее записанные ролики аватара.

| | Вариант 1 (рабочий) | Вариант 2 (это демо) |
|---|---|---|
| Страница | `:8000/avatar` | **`:8100/`** |
| Картинка | Pixel Streaming с render-ПК (Unreal) | записанные ролики `idle.mp4` / `talk.mp4` |
| Звук ответа | играет в плеере по событию `aidos_speak` | играет на странице по окончании `/voice` |
| Липсинк | да (аватар реально проговаривает) | **нет** (ролик — «говорящая» подложка) |
| Нагрузка | GPU render-ПК + Unreal 24/7 | почти нулевая |
| Вопрос→ответ | STT→RAG→TTS (`:8000`) | **тот же** STT→RAG→TTS (проксируем на `:8000`) |

Пайплайн у обоих вариантов **один и тот же** — отличается только источник картинки.
Поэтому сравнение честное, и вариант 1 не задет ни одной строчкой.

## Как это работает

```
микрофон (браузер :8100) → POST :8100/voice ──прокси──► :8000/voice
                                                          │ STT → RAG → TTS
                          ◄──── WAV + X-Question/X-Answer ┘
   <audio> играет WAV  +  <video id=talk> (немой, зациклен) поверх idle
   звук кончился → возвращаемся на idle.mp4
```

Прокси нужен, чтобы страница и её запросы были **same-origin** — иначе в рабочий
бэкенд пришлось бы добавлять CORS (то есть трогать вариант 1).

## Ролики (положить перед запуском)

```
video_ui/static/video/idle.mp4   — аватар стоит/молчит (крутится в цикле всегда)
video_ui/static/video/talk.mp4   — аватар говорит, ЛЮБОЙ текст (звук не важен — мы его глушим)
```

Требования — минимальные, ролики не обязаны совпадать по длине с ответом:
- **`talk.mp4` зацикливается** на всю длину звука, поэтому короткого ролика (5–10 c)
  достаточно даже для минутного ответа. Лучше, если начало и конец ролика похожи —
  тогда шов на стыке цикла не бросается в глаза.
- **`idle.mp4`** — тоже в цикле; чем длиннее и спокойнее, тем естественнее.
- Формат: **MP4/H.264 + AAC** (самый совместимый с браузерами). Звук в файлах может
  быть — он всё равно заглушён (`muted`).
- Оба ролика лучше одного разрешения/кадрирования — тогда переключение незаметно.
- Аспект подгоняется параметром `?ar=` (см. ниже), кадр масштабируется `object-fit: cover`.

⚠️ **Имена — строго в нижнем регистре.** macOS не различает регистр, поэтому `Idle.mp4`
там играет как ни в чём не бывало, а на **Linux (сервер АФМ) регистр важен** — те же файлы
дадут 404 и чёрный экран ровно на пилоте. `/health` сверяет имена точно (через `listdir`),
поэтому ловит это и на маке.

Проверить, что файлы на месте: `curl http://localhost:8100/health` → `"videos": {"idle.mp4": true, "talk.mp4": true}`.

## Запуск

```bash
bash run_api.sh          # 1) рабочий бэкенд (:8000) — как обычно
bash video_ui/run.sh     # 2) демо варианта 2 (:8100), в другом терминале
```

Открыть: `http://localhost:8100/` (киоск: `http://<IP>:8100/?kiosk=1&ar=9/16`).

Переменные окружения:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `AIDOS_BACKEND` | `http://localhost:8000` | Рабочий бэкенд, если он на другой машине |
| `AIDOS_BACKEND_TIMEOUT` | `300` | Таймаут `/voice` (TTS на CPU может идти минуты) |
| `VIDEO_UI_PORT` | `8100` | Порт демо |

Параметры страницы: `?kiosk=1` — режим киоска (крупные кнопки, бейдж языка);
`?ar=9/16` (или `1/1`, `16/9`) — пропорция области видео под аспект роликов.

## Нюансы

- **Микрофон по http требует secure-context** — та же граница, что и у варианта 1:
  по `http://<IP>:8100` браузер не даст записать звук. Лечится флагом
  `chrome://flags/#unsafely-treat-insecure-origin-as-secure` (вписать `http://<IP>:8100`)
  или HTTPS. Подробно — `PILOT.md` §B8.
- **Звук ответа требует жеста** — снимается автоматически: по клику «Задать вопрос»
  проигрывается тишина-заглушка, поэтому пришедший через секунды WAV уже играет.
  Отдельной плашки «включить звук» нет. Немое видео (`muted`) жеста не требует —
  idle крутится сразу.
- **Новых зависимостей нет** — используется основной `.venv`
  (`fastapi`/`uvicorn`/`httpx`/`python-multipart` уже там).
- **Ролики в git**: если они тяжёлые (десятки МБ), не коммить — копировать на сервер
  руками (`scp`), иначе репозиторий распухнет.
